SMS Opt-In — Match Notifications

Karmine is a peer-to-peer platform where Clash Royale players queue up to be matched against real opponents for 1v1 matches. When two players are matched, Karmine sends a one-time text message containing the opponent's in-game friend link so the match can be set up. This SMS program is used solely to send event-related match notifications to users who have opted in to be matched for games.

Opting in to SMS is optional and is not required to create a Karmine account. If you don't opt in, your opponent's friend link is still shown to you inside the app after each match — you just won't receive it by text.
